# bank-quiz-builder

把 **PDF 版题库（试题 + 解析）** 一键转换成一个 **单文件 HTML 刷题程序**：双击就能在浏览器里做题，自动判分、看解析、存进度，不联网、不依赖任何后端。

原始用例：银行科技岗行测 200 题（判断推理 / 数量关系 / 言语理解 / 资料分析），
输出 `银行行测200题刷题.html`（约 2MB，图片 base64 内嵌）。

> ⚠️ 本仓库**只包含代码**，不含任何真题 PDF 与提取出的题目数据。
> 题库内容受版权保护，请自行放在本地，用下面的流程生成。

---

## 快速开始

```bash
pip install -r requirements.txt      # 只依赖 PyMuPDF

# 1. 编辑 config.py：填 PDF 目录、模块名、文件名
# 2. 一键构建
python run_all.py
```

跑完会在**上级目录**生成 `银行行测200题刷题.html`，双击打开即可刷题。

可选：`python config.py` 会列出 PDF 目录下的所有 PDF，并校验配置里的文件名是否都存在。

---

## 新增 / 更换题库：只改 `config.py`

1. 把新的「试题 PDF」和「试题解析 PDF」放进 `PDF_DIR` 目录
2. 在 `MODULES` 里复制一行，改三处：模块 key、显示名、两个文件名
3. 把 key 加到 `MODULE_ORDER`（决定首页卡片顺序）
4. `python run_all.py`

```python
MODULES = {
    'pd': {
        'name': '判断推理',
        'q': '科技岗6大行行测200题-历3年考试真题-判断推理-试题.pdf',
        'a': '科技岗6大行行测200题-历3年考试真题-判断推理-试题解析.pdf',
    },
    # 新增示例
    # 'cs': {'name': '常识判断', 'q': '常识判断-试题.pdf', 'a': '常识判断-试题解析.pdf'},
}
MODULE_ORDER = ['pd', 'sl', 'yy', 'zl']   # 加上 'cs'
```

### 新 PDF 需要满足的格式

| 文件 | 要求 |
|---|---|
| 试题 PDF | 题号形如 `1.` / `1、`；选项形如 `A.` `B.` `C.` `D.` |
| 解析 PDF | 每条形如 `1.【答案】C。解析：……` |

格式不同则改 `parse.py` 里的 `Q_START` / `A_START` 正则。

### 其他常见调整

| 情况 | 改哪里 |
|---|---|
| 新 PDF 有水印 | `config.py` → `WATERMARKS` / `CELL_WATERMARK_CHARS` |
| 新模块有共享材料（一/二/三、 大段材料多题共用） | 把 key 加进 `MATERIAL_MODULES` |
| 改页面标题 / 输出文件名 | `config.py` → `TITLE` / `H1` / `SUB` / `OUT_HTML` |

## 目录结构

| 文件 | 作用 |
|---|---|
| `config.py` | **唯一需要编辑的文件**：PDF 目录、模块表、顺序、水印、输出 |
| `run_all.py` | 一键流水线：校验配置 → 清空旧图 → 提取 → 解析 → 打包 |
| `extract.py` | PDF → 规范化文本（坐标排序、表格转 markdown、图片定位、去水印） |
| `parse.py` | 文本 → 结构化题库（切题、切选项、匹配答案解析、渲染图片） |
| `build_html.py` | 题库 JSON + 图片 → 单文件 HTML（base64 内嵌） |
| `verify.js` | 回归校验（可选，需 Node.js）：题数、答案、图片、逐题渲染 |

---

## 生成物的功能

- 首页按模块显示进度条与正确率，支持「全部 / 未做 / 错题 / 随机」模式
- 点击选项即时判分，展开解析；资料分析题会展示共享材料（表格 + 图）
- 答题卡跳转、收藏、上一题 / 下一题
- 进度存 `localStorage`，关掉浏览器再开还在
- 键盘快捷键：`A~D` 作答，`←` `→` 翻题

## 实现里的几个关键点

PDF 转结构化题目没什么银弹，下面这些坑都踩过并已在代码里处理：

- **双栏排版乱序**：按词的坐标重排（y 聚类成行、行内按 x 排序），否则 A/C 和 B/D 会串栏
- **图形题**：既有位图也有矢量 drawing，两者都要检测；相邻图形按间距聚类，间隙里有正文才不合并
- **水印**：正文词级过滤 + 表格单元格里的单字（如 `店1.26`）+ 数字前缀单字
- **题号误判**：`3.14%` 是小数不是题号；`注：1.xxx 2.xxx` 是材料注释不是题目 —— 用「题号递增」和「后续窗口内必须出现选项行」双重校验
- **跨页表格**：识别续表并合并
